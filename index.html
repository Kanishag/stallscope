    Cloud check

    Sends your program to the StallScope cloud API. The API runs its own simulation, tries every safe order of the instructions, and a machine learning model, trained on programs simulated with PySpark, estimates how many cycles a better order could save without searching.

    Branch lab

    A branch makes the CPU guess which instruction comes next. Every wrong guess throws away 2 cycles of work. The last box assumes 1 in 5 instructions is a branch.
